Les bases de l'HTML

Les balises de bases:

C'est les premières balises à placer dans une page web pour créer du contenu.

<!doctype html> <-- console -->

c'est normal que la console n'affiche rien.

La balise "!doctype html" sert à commencer à coder en HTML, c'est aussi pour dire quelle version utiliser.

Maintenant, voyons la suite

<!doctype html>   <head>     <title> titre de la page </title>   </head>   <body>   </body> <-- console -->

rien ne s'affiche et c'est normal, voyons chaqunes de ces balises.

head c'est la zone où on vas mettre toutes les infos du site (title, lien avec le fichier css, etc).

title c'est le titre de la page web (celui qui s'affiche en haut de l'onglet).

body c'est la zone où on vas mettre tout le contenu visible de la page web.

continuons sur ce qu'on peux mettre dans la balise body.

Les balises de contenu:

Les balises h1 à h6 créent des titres. Ainsi que les balises p pour les paragraphes.

Les balises img permettent d'insérer des images dans la page. Aisni que les balises a pour les liens.

La balise spéciale <br> est une balise sans fermeture pour insérer des espaces.

Les balises div et span sont des conteneurs génériques pour regrouper d'autres éléments.

Les balises ul, ol et li permettent de créer des listes. ul pour les listes non ordonnées, ol pour les listes ordonnées, et li pour les éléments de liste.

Les balises comme input, button, textarea, select, permettent de créer des éléments d'interface interactifs.

Les balises de head

Les balises meta fournissent des métadonnées sur le document HTML, telles que la description, les mots-clés, et les paramètres de viewport.

<head>   <meta charset="UTF-8">   <meta name="viewport" content="width=device-width, initial-scale=1.0">   <meta name="description" content="Description de la page"> </head> <-- console -->

Puis ensuite les attributs lang pour définir la langue du contenu (ex. <html lang="fr">) et role pour améliorer l'accessibilité (ex. role="navigation").

Les attributs HTML

Les attributs HTML

Les attributs HTML sont des informations supplémentaires que l'on peut ajouter aux balises pour modifier leur comportement ou leur apparence.

Par exemple, l'attribut href dans la balise a spécifie l'URL de destination du lien, et l'attribut src dans la balise img spécifie le chemin de l'image à afficher.

Il existe de nombreux autres attributs HTML, tels que class, id, style, alt, title, target, et d'autres, chacun ayant une fonction spécifique.

Comme par exemple, l'attribut class permet de donner un nom à un élément pour pouvoir le cibler en CSS, et l'attribut id permet de donner un nom unique à un élément.

Ces noms pourront ensuite être utilisés dans les sélecteurs CSS et JavaScript (ou Python).

Il y a aussi les balises strong et em pour indiquer l'importance et l'emphase du texte.

Les bases du CSS
Associer CSS à l'HTML

Associer CSS à l'HTML

Pour associer une feuille de style CSS à un document HTML, on utilise la balise <link> dans la section <head> du document HTML.

<head>   <link rel="stylesheet" href="styles.css"> </head> <-- console --> <head>   <link rel="stylesheet" href="styles.css"> </head>

Dans cet exemple, l'attribut rel spécifie le type de relation entre le document HTML et la feuille de style. Ici, stylesheet indique une feuille de style.

L'attribut href indique le chemin vers le fichier CSS. Ici, il s'agit de styles.css

Les sélecteurs CSS

Les sélecteurs CSS

Les sélecteurs CSS sont utilisés pour cibler des éléments HTML spécifiques afin d'appliquer des styles.

Il existe plusieurs types de sélecteurs : les sélecteurs de type, les sélecteurs de classe et les sélecteurs d'identifiant.

Chaque sélecteur est suivi d'un bloc de déclaration entre accolades {} où les propriétés CSS sont définies.

Sélécteur de type:

p {   color: blue; }

Sélecteur de classe (.element):

.highlight {   background-color: yellow; }

Sélecteur d'identifiant (#element):

#main-title {   font-size: 24px; } <-- console -->

Dans ces exemples, on montre trois types de sélecteurs : le sélecteur de type, de classe et d'identifiant.

ils sont équipés de préfixes spécifiques pour les distinguer: {rien}, {.}, et {#}

Les propriétés CSS

Les propriétés CSS

Les propriétés CSS sont utilisées pour définir les styles à appliquer aux éléments HTML sélectionnés.

p {   color: red;   font-size: 16px;   margin: 10px; } <-- console -->

Commentaires

Les commentaires en CSS sont utilisés pour ajouter des notes ou des explications dans le code CSS sans affecter son fonctionnement.

/* Ceci est un commentaire en CSS */ p {   color: blue; /* Couleur du texte */ } <-- console -->

Dans cet exemple, on montre comment écrire des commentaires en CSS en utilisant la syntaxe /* commentaire */.

Les commentaires peuvent être placés n'importe où dans le code CSS et sont ignorés par le navigateur lors de l'interprétation du style.

Il en existe aussi en HTML, JavaScript et Python :

  • HTML : <!-- Ceci est un commentaire en HTML -->
  • JavaScript : // Ceci est un commentaire sur une ligne
  • JavaScript : /* Ceci est un commentaire sur plusieurs lignes */
  • Python : # Ceci est un commentaire en Python

JavaScript

Le Javascript est essentiel pour rendre une page web interactive. Il permet de manipuler le DOM (Document Object Model) pour modifier le contenu, la structure et le style d'une page web en temps réel.

Variables en JavaScript

En JavaScript, les variables sont utilisées pour stocker des données et des valeurs. Il existe trois mots-clés principaux pour déclarer des variables : var, let et const.

var nom = "Alice"; let age = 30; const isStudent = true; <-- console-->

let est une variable dont la valeur peut être modifiée après son initialisation. Ce qui n'est pas le cas de const. Cependant var est la seule à permettre la redéclaration d'une variable, tandis que let et const ne le permettent pas.

La valeur de la variable est sois une chaîne de caractères, un nombre, un booléen, un tableau ou un objet.

Voici quelques exemples:

let nom = "Alice"; let age = 30; let isStudent = true; let fruits = ["apple", "banana", "orange"]; let person = { name: "Alice", age: 30, speak() {console.log("Hi !");}} console.log(nom, age, isStudent, fruits[0], person.name); <-- console--> > Alice 30 true apple Alice

Les variables peuvent également être destructurés et devenir des fonctions fléchées:

let nom = ["Alice", "Bob", "Charlie"]; let [name1, name2, name3] = nom; console.log(name1 + ", " + name2 + ", " + name3); <-- console--> > Alice, Bob, Charlie

On utilise "," pour ignorer des éléments du tableau et "..." + name pour capturer les éléments restants dans un tableau. la destructuration fonctionne aussi avec les objets.

const [, name2, ...rest] = nom;

Ensuite les fonctions fléchées qui agissent comme des fonctions anonymes:

const add = (a, b) => a + b; console.log(add(5, 3)); <-- console--> > 8

Elles permettent de créer des fonctions plus concises et lisibles.

Attention, les fonctions fléchés ne retournent pas toujours this. Si elles contiennent { } pour faire plusieurs lignes, il faudra utiliser le mot-clé return.

function square(x) { return x * x; } console.log(square(5)); <-- console--> > 25

Un autre outil utile est le Template Literals, utilisant les backticks (`)

let name = "Alice"; let greeting = `Hello, ${name}!`; console.log(greeting); <-- console--> > Hello, Alice!

Tableaux

Les tableaux sont des structures de données qui permettent de stocker plusieurs valeurs dans une seule variable. En JavaScript, les tableaux sont créés en utilisant des crochets [] et peuvent contenir des éléments de différents types.

let fruits = ["apple", "banana", "orange"]; console.log(fruits[0]);

// Accéder au premier élément

console.log(fruits.length);

// Obtenir la longueur du tableau

<-- console--> > apple > 3

La manipulation des tableaux est une compétence essentielle en JavaScript. Voici quelques méthodes couramment utilisées:

Tout d'abord, on peut accéder à un élément spécifique du tableau en utilisant son index:

let fruits = ["apple", "banana", "orange"]; console.log(fruits[1]);

// Accéder au deuxième élément

<-- console--> > banana

Ensuite, on peut ajouter un élément à la fin du tableau avec la méthode push:

fruits.push("grape"); console.log(fruits); <-- console--> > ["apple", "banana", "orange", "grape"]

On peut également supprimer le dernier élément du tableau avec la méthode pop:

fruits.pop(); console.log(fruits); <-- console--> > ["apple", "banana", "orange"]

Pour trier les éléments du tableau, on utilise la méthode sort:

fruits.sort(); console.log(fruits); <-- console--> > ["apple", "banana", "orange"]

Voyons plus frofondement ce qui est possible avec les tableaux: Utilisons les outils .filter, .map, et .reduce dans des exemples concrets.

fruits.map(function(element, index) { return element.toUpperCase(); });

.map permet de créer un nouveau tableau en appliquant une fonction à chaque élément du tableau d'origine.

fruits.filter(function(x) { return x.length > 5; });

.filter permet de créer un nouveau tableau contenant uniquement les éléments qui satisfont une condition spécifiée.

fruits.reduce(function(accumulator, element) { return accumulator + element.length; }, 0);

.reduce permet de réduire le tableau à une seule valeur en appliquant une fonction d'accumulation à chaque élément du tableau.

La Structure des Tableaux:

On va voir plus visiblement comment coder des .map, .filter et .reduce. tout ça paraît complexe au départ, mais avec un peu de pratique, vous maîtriserez ces outils puissants.

let numbers = [1, 2, 3, 4, 5]; console.log(numbers); <-- console--> > [1, 2, 3, 4, 5]

Pour l'exemple, nous utiliserons uniquement .map, mais .filter et .reduce ont exactement les mêmes principes.

Tout d'abord, rappelons le tableau. Puis ajoutons lui .map

numbers.map()

Ce .map est vide, ajoutons lui une fonction.

numbers.map(function() {})

Ici on a ajouté la fonction .map avec les crochets pour ce qu'elle va exécuter. La fonction s'exécute sur chaque élément du tableau au rendu. La fonction prend deux paramètres: element et index. Element est l'élément du tableau sur lequel la fonction s'exécute, et index est l'index de cet élément dans le tableau. C'est à dire que Element est la valeur de l'élément, et index est sa position dans le tableau. Par exemple, si on a un tableau [10, 20, 30], element 10 aura Element = 10 et index = 0 .

console.log( numbers.map(function(element, index) { return element * index; }) );

Chaques éléments du tableau sont multipliés par leur index, la valeur est renvoyée dans la console.

Boucles & Manipulation du DOM

Il existe 3 boucles en JavaScript: for, while, et do...while

while est une boucle qui s'exécute tant qu'une condition est vraie.

for est une boucle qui s'exécute un nombre spécifique de fois en utilisant sa propre variable d'initialisation, de condition et d'incrémentation.

do...while est une boucle qui s'exécute au moins une fois, puis continue tant qu'une condition est vraie.

Exemple de boucle for:

for (let i = 0; i < 5; i++) {    console.log("Itération " + i); }

Exemple de boucle while:

let j = 0; while (j < 5) {    console.log("Itération " + j);    j++; }

Exemple de boucle do...while:

let k = 0; do {    console.log("Itération " + k);    k++; } while (k < 5);

Événements en JavaScript
Introduction aux événements

Les événements en JavaScript sont des actions ou des occurrences qui se produisent dans le navigateur (clics, double-clics, défilement, saisie, gestes tactiles, etc.). On peut y répondre en attachant des gestionnaires (handlers) ou des écouteurs (event listeners).

Voyons comment les utiliser dans notre code:


                            
Exemple d'écouteur d'événement:

                            const button = document.querySelector("button"); 
                            button.addEventListener("click", function() { 
                               console.log("Bouton cliqué !"); 
                            });  

                            
Exemple de gestionnaire d'événement:

                            button.onclick = function() { 
                               console.log("Bouton cliqué !"); 
                            };

Sur ces deux approches, l'approche avec `addEventListener` est généralement préférée car elle offre plus de flexibilité et de contrôle.

Il existe plusieurs types d'événements, comme `click`, `mouseover`, `keydown`, etc. Voici la liste complète:

  • `click` - Clic sur un élément
  • `dblclick` - Double-clic sur un élément
  • `mouseover` - survol d'un élément
  • `keydown` - touche pressée
  • `keyup` - touche relâchée
  • `focus` - élément reçoit le focus
  • `blur` - élément perd le focus
  • `submit` - formulaire soumis
  • `change` - valeur d'un élément modifiée
  • `input` - saisie dans un champ de texte
  • `scroll` - défilement d'un élément
  • `resize` - redimensionnement de la fenêtre
  • `touchstart` - début d'un geste tactile
  • `touchmove` - mouvement d'un geste tactile
  • `touchend` - fin d'un geste tactile
  • `touchcancel` - annulation d'un geste tactile

                            
Apprendre à utiliser les événements en JavaScript. On va faire un bouton qui affiche un message dans la console quand on clique dessus.

                            
Tout d'abord, on sélectionne le bouton :

                            const button = document.querySelector("button"); 
                            
Ensuite, on ajoute un écouteur d'événement pour le clic :

                            button.addEventListener("click", greetings) 
                            
Enfin, on définit la fonction qui sera appelée lors du clic :

                            function greetings() { 
                               console.log("Hello World!"); 
                            }

Il existe aussi RemoveEventListener pour retirer un écouteur d'événement :

button.removeEventListener("click", greetings);

Asynchrone

Le code Asynchrone et Sychrone est quelque chose de spécial dont a vaguement parler auparavant.

Le code synchrone s'exécute ligne par ligne, tandis que le code asynchrone permet à certaines opérations (comme les requêtes réseau ou les timers) de s'exécuter plus tard, sans bloquer le fil principal.

On avait déjà vu les fonctions asynchrones, et maitenant nous allons découvrir d'autres concepts asynchrones.

Exemple de code synchrone :

console.log("Début"); console.log("Fin"); <-- console--> > Début > Fin

Exemple de code asynchrone avec setTimeout :

console.log("Début"); setTimeout(function() {    console.log("Asynchrone"); }, 1000); console.log("Fin"); <-- console--> > Début > Fin > Asynchrone (après 1 seconde)

Deux concepts asynchrones importants sont SetTimeout et SetInterval.

SetTimeout permet d'exécuter une fonction après un certain délai (en millisecondes). SetInterval permet d'exécuter une fonction de manière répétée à intervalles réguliers. ClearInterval permet d'arrêter un intervalle. C'est secondaire mais utilise pour la gestion des performances.

Introduction à Express

Express est un framework web pour Node.js qui simplifie la création d'applications web et d'API. Il fournit des fonctionnalités pour gérer les routes, les requêtes et les réponses HTTP.

Entre autres, express agit comme middleware (je fait ça avant toi).

Voici un exemple simple d'application Express :

Mise en place d'Express :

const express = require('express'); const app = express();

Configuration du port :

const port = 3000;

Dans cette exemple, nous avons créé une application Express simple qui écoute sur le port 3000

On peux aussi exporter et importer des modules dans notre application Express:

Dans le fichier server.js :

const routes = require('./routes'); app.use('/api', routes); export default app;

Dans le fichier routes.js :

import app from './server.js'; const router = express.Router(); router.get('/data', (req, res) => { res.json({ message: 'Données récupérées avec succès !' }); }); module.exports = router;

routes est une variable qui récupère les routes définies et app.use('/api', routes) les utilise dans l'application principale sous le chemin '/api'
Dans le fichier routes.js, on récupère app qui avait été exporté, et on crée un router Express pour définir les routes. router.get() crée une route "/data" qui répond avec un message JSON.

Ce qu'il faut retenir, imaginons https://example.com/api/data, l'adresse du site c'est https://example.com et /api c'est le chemin de l'API et /data est le chemin spécifique à la route.

Pour importer exporter plusieurs objets, on peut utiliser les exportations nommées et les importations avec { } (et même les renommer ex: import {pi as malware, john})

Les routes dans Express peuvent inclure des paramètres qui permettent de capturer des valeurs spécifiques dans l'URL.

Exemple de route avec paramètre :

app.get('/users/:id', (req, res) => { const userId = req.params.id; res.json({ id: userId }); });

Dans cet exemple, le paramètre `:id` capture la valeur de l'ID utilisateur dans l'URL. sur https://example.com/api/users/123, l'ID utilisateur est 123.

Nous utilisons get pour récupérer les données. Il y a aussi d'autres méthodes HTTP: post, put, delete et patch

Get permet de récupérer des ressources. Post permet de créer de nouvelles ressources. Put permet de mettre à jour une ressource existante. Delete permet de supprimer une ressource. Patch permet de mettre à jour partiellement une ressource.

Différentes manières ensuite de répondre aux requêtes HTTP :

Exemple de réponse avec res.send :

app.get('/hello', (req, res) => { res.send('Hello World!'); });

Exemple de réponse avec res.json :

app.get('/data', (req, res) => { res.json({ message: 'Données récupérées avec succès !' }); });

Exemple de réponse avec res.status :

app.get('/error', (req, res) => { res.status(200).send('OK'); });

.send envoie une réponse simple sous forme de chaîne de caractères. .json envoie une réponse JSON. .status permet de définir le code de statut HTTP de la réponse.

Enfin, il y a req.body pour accéder aux données envoyées dans le corps de la requête (souvent utilisé avec POST et PUT).

Exemple d'utilisation de req.body :

app.use(express.json());

Nous verons ça plus tard, juste ignore le ;-

On récupère les données envoyées dans le corps de la requête en utilisant req.body.

Middleware

Les middlewares sont des fonctions qui s'exécutent pendant le cycle de vie d'une requête HTTP dans une application Express. Ils peuvent être utilisés pour effectuer des tâches telles que l'authentification, la journalisation, la validation des données, etc.

Pour en dire bref, les middlewares sont des fonctions intermédiaires qui permettent de manipuler les requêtes et réponses HTTP dans une application Express.

Voici un exemple simple de middleware :

Exemple de middleware :

app.use(express.json());

permet de parser le corps des requêtes JSON

ou

app.use(express.urlencoded());

permet de parser le corps des requêtes URL-encoded

Parser signifie "analyser" ou "traiter" au cas où.

Donc:

app.use(express.json()); const myMiddleware = (req, res, next) => { console.log('Middleware exécuté !'); next(); }; app.use(myMiddleware);

Dans le code ci-dessus, nous créons la variable `myMiddleware` qui contient une fonction middleware. Nous l'utilisons ensuite avec `app.use(myMiddleware)` pour l'appliquer à toutes les routes.

Il y a aussi une manière de procéder différement.

Clarifions, express.json() est un middleware déjà intégré à Express.js qui permet de lire les body des requêtes JSON, qui sont des données structurées au format JSON comme les objets JavaScript.

Exemple de middleware spécifique :

const myMiddleware = (req, res, next) => { console.log('Middleware exécuté !'); next(); }; app.put('/hello', myMiddleware, (req, res) => { const name = req.body.name; res.send(`Hello ${name}!`); }); app.use(express.json());

Dans cet exemple, le middleware `myMiddleware` est appliqué uniquement à la route `/hello`. Il s'exécutera avant le gestionnaire de la route et affichera "Middleware exécuté !" dans la console.

petit exemple avec 2 middlewares:

Exemple de deux middlewares :

const middleware1 = (req, res, next) => { console.log('Middleware 1 exécuté !'); next(); };

Avec next() on passe au middleware suivant, sans next(), on coupe la chaîne de middleware. next() va chercher le prochain middleware dans la chaîne ou ceux par app.use()

const middleware2 = (req, res, next) => { console.log('Middleware 2 exécuté !'); next(); }; app.get('/hello', middleware1, middleware2, (req, res) => { res.send('Hello World!'); });

ici, définir middleware2 n'est pas nécessaire si middleware2 est dans la chaîne de middlewares.
Middlewares avec routes

App.js

const express = require('express'); const app = express(); const router = express.Router(); const UserRoutes = require('./userRoutes'); module.exports = router;

Router.js

router.route('/item/:id').get((req, res) => { res.send('Get a book'); }).put((req, res) => { res.send('Update a book'); }).delete((req, res) => { res.send('Delete a book'); });

Il y a beaucoup de chose à expliquer, voici une liste d'infos :

  • const router = express.Router(); : Crée un mini router Express.
  • UserRoutes : Importe un autre routeur Express.
  • router.route() permet de définir plusieurs méthodes HTTP pour une même route.
    Tu aurais dû faire router.get() puis router.put() etc. Sauf que tu fait router.route().get(get).put(put).delete(delete)
  • router.use() : Applique un middleware à toutes les routes du routeur. N'était pas dans l'exemple précédent.
  • router.route().all((req, res, next) => { ... }) : Applique un middleware à toutes les méthodes HTTP d'une route.

Pour router.route().all([x, y]), x et y peuvent être des middlewares prédéfinis à l'avance et dont la référence est passée en paramètre. Les [ ] représentent un tableau de middlewares, pas nécessaire si il n'y en a qu'un seul.

Si nous voulons qu'une seule des routes déclanche le middleware, nous pouvons l'appliquer directement à cette route.

Middlewares avec .all()

const express = require('express'); const app = express(); const middleware1 = (req, res, next) => { console.log('Middleware 1 exécuté !'); next(); }; const middleware2 = (req, res, next) => { console.log('Middleware 2 exécuté !'); next(); }; router.route('/item/:id') .all(middleware1) .get(middleware2, (req, res) => { res.send('Get a book'); }) .put((req, res) => { res.send('Update a book'); }) .delete((req, res) => { res.send('Delete a book'); });

.get, .put et .delete éxécutent middleware1, et .get utilise middleware2 en plus.

Il existe aussi fetch() qui permet de faire des requêtes HTTP (c'est une fonction cliente), res.redirect(301, "/new-path") qui redirige vers une autre route.
le code 301 représente une redirection permanente. 302 représente une redirection temporaire.

Bienvenue sur SQL 😃, un language qui vous feras des merveilles ! Vous allez adorer !

Users ===================== | ID | Nom | Âge | |----|--------|-----| | 1 | Alice | 25 | | 2 | Bob | 30 | | 3 | Charlie| 22 | | 4 | David | 25 | =====================

Première étape, essayons de séléctionner un élément du tableau. Nous avons un tableau nommé 'Users', séléctionnons-le tableau entier.

SELECT ID, Nom, Âge FROM Users;

La console affiche tous le tableau.

La première instruction en SQL, c'est SELECT. Il permet de sléctionner un ou des éléments. Ensuite, nous spécifions les colonnes que nous voulons récupérer.

Biensûr, on doit spécifier quel tableau nous voulons utiliser. Nous le justifions avec le mot-clé FROM puis le nom du tableau.

Une manière pour tous séléctionner du tableau est d'utiliser l'astérisque (*) :

Exemple de requête SQL :

SELECT * FROM Users;

La console affiche tous le tableau.

Si nous vonlons séléctionner le colonne âge spécifique afin de voir les âges qu'ont les utilisateurs, nous risquons d'avoir des valeurs doublées.

Pour cela, nous utilisons DISTINCT SELECT

Exemple de requête SQL :

SELECT DISTINCT Âge FROM Users;

La console affiche les âges distincts : 25, 30, 22.

Pour filtrer les résultats, nous utilisons le mot-clé WHERE. Il permet de spécifier une condition pour les lignes que nous voulons récupérer.

Exemple de requête SQL :

SELECT * FROM Users WHERE Âge = 25;

La console affiche les utilisateurs ayant 25 ans : Alice et David.

Les opérateurs en SQL sont :

  • = : égal à
  • <> : différent de
  • > : supérieur à
  • < : inférieur à
  • >= : supérieur ou égal à
  • <= : inférieur ou égal à

Si nous voulons trier les résultats, nous utilisons le mot-clé ORDER BY. Il permet de spécifier la colonne par laquelle nous voulons trier les lignes.

SELECT * FROM Users ORDER BY Âge ASC;

La console affiche les utilisateurs triés par âge croissant.



SELECT * FROM Users ORDER BY Âge DESC;

La console affiche les utilisateurs triés par âge décroissant.

Enfin nous pouvons renommer les colonnes dans les résultats en utilisant le mot-clé AS.

SELECT Nom AS NomUtilisateur, Âge AS AgeUtilisateur FROM Users;

La console affiche les colonnes renommées : NomUtilisateur et AgeUtilisateur.

Il existe aussi pour WHERE: BETWEEN, LIKE, et IN avec AND, OR, NOT.

Exemple d'utilisation de BETWEEN :

SELECT * FROM Users WHERE Âge BETWEEN 25 AND 30;

La console affiche les utilisateurs ayant un âge compris entre 25 et 30 ans : Alice, Bob et David.

Exemple d'utilisation de LIKE :

SELECT * FROM Users WHERE Nom LIKE 'A%';

La console affiche les utilisateurs dont le nom commence par 'A' : Alice. "%" correspond à une séquence de caractères quelconques.

Exemple d'utilisation de IN :

SELECT * FROM Users WHERE Nom IN ('Alice', 'Bob');

La console affiche les utilisateurs dont le nom est soit 'Alice' soit 'Bob'.

Exemple d'utilisation de AND :

SELECT * FROM Users WHERE Âge > 25 AND Nom = 'Bob';

La console affiche les utilisateurs ayant un âge supérieur à 25 ans et dont le nom est 'Bob'.

Exemple d'utilisation de OR :

SELECT * FROM Users WHERE Âge < 25 OR Nom = 'David';

La console affiche les utilisateurs ayant un âge inférieur à 25 ans ou dont le nom est 'David'.

Exemple d'utilisation de NOT :

SELECT * FROM Users WHERE NOT Nom = 'Charlie';

La console affiche tous les utilisateurs sauf ceux dont le nom est 'Charlie'.

Puis dans la lancée, il y a les fonctions d'agrégation comme COUNT, SUM, AVG, MIN et MAX.

Exemple d'utilisation de COUNT :

SELECT COUNT(*) AS NombreUtilisateurs FROM Users;

La console affiche le nombre total d'utilisateurs : 4.

Exemple d'utilisation de SUM :

SELECT SUM(Âge) AS SommeAges FROM Users;

La console affiche la somme des âges des utilisateurs : 102.

Exemple d'utilisation de AVG :

SELECT AVG(Âge) AS AgeMoyen FROM Users;

La console affiche l'âge moyen des utilisateurs : 25.5.

Exemple d'utilisation de MIN :

SELECT MIN(Âge) AS AgeMinimum FROM Users;

La console affiche l'âge minimum des utilisateurs : 22.

Exemple d'utilisation de MAX :

SELECT MAX(Âge) AS AgeMaximum FROM Users;

La console affiche l'âge maximum des utilisateurs : 30.

Pour le plus complexe avec la relation entre les tables, on peut utiliser des jointures (JOIN).

cette catégorie est plus avancée:

INNER JOIN :

SELECT * FROM artist JOIN album ON artist.artist_id = album.artist_id;

La console affiche les artistes et leurs albums correspondants, avec une jointure interne entre deux tables.

Il existe aussi LEFT JOIN, RIGHT JOIN et FULL OUTER JOIN.

Voici comment marche les 4 JOIN :

  • INNER JOIN : Affiche les enregistrements qui ont des correspondances dans les deux tables.
  • LEFT JOIN : Affiche tous les enregistrements de la table de gauche, même s'il n'y a pas de correspondance dans la table de droite.
  • RIGHT JOIN : Affiche tous les enregistrements de la table de droite, même s'il n'y a pas de correspondance dans la table de gauche.
  • FULL OUTER JOIN : Affiche tous les enregistrements des deux tables, avec des NULL pour les correspondances manquantes.
Alterations

Avec SQL, on peut modifier la structure d'une table en utilisant des commandes comme INSERT INTO et bien d'autres:

Exemple d'insertion de données :

INSERT INTO Users (Nom, Âge) VALUES ('Eve', 28);

La console affiche un tableau avec l'utilisateur Eve ajouté à la table Users avec les valeurs spécifiées.

DELETE FROM Users WHERE Nom = 'Bob';

La console affiche un tableau avec l'utilisateur Bob supprimé de la table Users.

UPDATE Users SET Âge = 26 WHERE Nom = 'Alice';

La console affiche un tableau avec l'âge de l'utilisateur Alice mis à jour à 26.

Avec db.exec() on peux exécuter des commandes SQL:

const Database = require('better-sqlite3'); const db = new Database('mydatabase.db'); db.exec("CREATE TABLE Users (ID INTEGER PRIMARY KEY, Nom TEXT, Âge INTEGER)");

Ici, on utilise SQL et on crée une table Users avec les colonnes ID, Nom et Âge.

Quelque chose d'import est d'importer SQL sur express, ce n'est pas automatique.

En express, il faut sécuriser la lecture des données.

const stmt = db.prepare('SELECT * FROM Users WHERE Nom = ?'); const user = stmt.get('Alice'); console.log(user);

Dans cet exemple, nous préparons une requête SQL avec un paramètre de substitution (le point d'interrogation). Ensuite, nous exécutons la requête en passant la valeur 'Alice' pour le paramètre. Cela permet d'éviter les injections SQL et de sécuriser la lecture des données.

La substitutuion des paramètres est une pratique importante pour assurer la maniabilité de l'application. Chaque ? ont un ordre, et l'insertion de valeurs suit cet ordre.

Dans l'exemple, on utilise la méthode get() pour récupérer un seul enregistrement.

Quand il y a plusieurs enregistrements à récupérer, on peut utiliser la méthode all() au lieu de get().


s'il y a beaucoup de données à insérer en même temps, on utilise:

const insertStmt = db.prepare('INSERT INTO Users (Nom, Âge) VALUES (?, ?)'); const insertMany = db.transaction((users) => { for (const user of users) { insertStmt.run(user.Nom, user.Âge); } }); const usersToInsert = [ { Nom: 'Frank', Âge: 29 }, { Nom: 'Grace', Âge: 31 }, { Nom: 'Hannah', Âge: 27 } ]; insertMany(usersToInsert);

Dans cet exemple, nous préparons une requête d'insertion avec des paramètres de substitution. Ensuite, nous créons une transaction en utilisant db.transaction() pour insérer plusieurs utilisateurs en une seule opération. Cela permet d'améliorer les performances et de garantir l'intégrité des données.

Autrement dit, les transactions permettent de grouper plusieurs opérations en une seule unité de travail.

La transaction agit comme une fonction fléchée. La méthode run() est appelée pour exécuter la requête avec les valeurs des paramètres.
